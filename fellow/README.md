# Fellow - 工数管理アプリ(プロトタイプ)

案件×要員×月の計画工数と、タイマー/手動入力による実績工数を管理するFletアプリ。

## セットアップ

```bash
pip install -r requirements.txt
python main.py
```

## 画面構成

- ホーム: タイマーで稼働時間を計測
- 手動入力: 後から時間帯を指定して記録を追加・編集
- 集計・ダッシュボード: 案件別の計画 vs 実績を表示
- 案件マスタ / 要員マスタ / 計画工数登録: マスタデータの管理

## データ

初回起動時に `fellow.db` (SQLite) が自動生成され、サンプルの案件・要員が投入されます。
ローカルDBはキャッシュであり、ファイルサーバー同期を設定すると、そちらが正になります。

## ファイルサーバー同期(チーム共有)

環境変数 `FELLOW_FILESERVER_ROOT` に共有フォルダのパス(UNCパスまたはドライブ文字、どちらも可)を設定すると、
以下のルールでマスタ・実績を同期する。

```
<FELLOW_FILESERVER_ROOT>/
  masters/
    projects.csv   ← 案件マスタ(正)。全員が読み込み、管理者操作時のみ書き戻す
    staff.csv      ← 要員マスタ(正)。同上
    plans.csv      ← 計画工数(案件×要員×月)(正)。同上
  actuals/
    <氏名>.csv     ← 各人の実績。本人のFellowだけが書き込む(1人1ファイルなので競合しない)
```

- 起動時と画面右上の同期ボタンで、マスタをファイルサーバーから読み込む(pull)
- 案件マスタ/要員マスタ/計画工数登録画面での保存時、ローカルDB更新に加えてファイルサーバーへ書き戻す(push)
- タイマー停止・手動入力の追加/削除時、自分の実績ファイルをファイルサーバーへ書き出す
- ダッシュボードの表示を「チーム」に切り替えると、全員の実績ファイルを読み込んで集計する
- ファイルサーバーに接続できない場合は、ローカルDBの内容で動作を継続し(オフライン耐性)、
  再接続時に同期ボタンを押すことで最新化できる
- CSVはUTF-8(BOM可)で書き込み、既存ファイルの読み込みはUTF-8失敗時にCP932(Shift-JIS)へフォールバックする

環境変数を設定しない場合、既定値 `\\fileserver\fellow` を参照する(実在しなければオフライン動作)。

## 配布方法(Python未インストール端末向け・exe化なし)

社内のセキュリティポリシーで未署名exeが実行できない場合、Pythonの
「embeddable package(展開版)」をアプリと同じフォルダに同梱し、
`.bat`ファイルから起動する方式を使う。

1. 開発者のWindows機で、[python.org](https://www.python.org/downloads/windows/) から
   使用中のPythonバージョンに合う「Windows embeddable package (64-bit)」の
   zipをダウンロードし、このフォルダに `python-embed.zip` として置く
2. `build_portable.bat` を実行する
   (Python本体の展開・pip有効化・`requirements.txt`のインストールまで自動で行う)
3. 完成した `fellow` フォルダ全体をZIP化してユーザーに配布する

### ユーザー側の使い方

1. 配布されたZIPを展開する
2. `run.bat` をダブルクリックする(インストール操作は不要)

この方式なら、実行されるのはPython公式配布の`python.exe`であり、
未署名の独自exeではないため、SmartScreenの警告やブロックの対象になりにくい。
ただし、配布フォルダのサイズは大きくなる(Python本体+ライブラリ+Flutter描画エンジン分)。
